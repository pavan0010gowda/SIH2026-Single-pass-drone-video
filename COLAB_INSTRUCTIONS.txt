1. OVERVIEW & CLOUD GPU ADVANTAGES
================================================================================
High-resolution 4K 10-minute UAV surveillance videos contain 18,000+ frames and 
weigh 3.5 GB or more. Running dense multi-view 3D photogrammetry (COLMAP SIFT 
matching, camera triangulation, dense MVS stereo, and Poisson surface meshing)
locally on consumer laptops or desktop GPUs (e.g., RTX 3050 4GB) can exhaust 
VRAM, cause thermal throttling, or take hours.

By offloading the heavy reconstruction to Google Colab or Kaggle:
- You utilize enterprise cloud GPUs with 16 GB to 40 GB of high-speed VRAM:
    * NVIDIA T4 GPU (Free tier, 16 GB VRAM)
    * NVIDIA V100 / A100 Tensor Core GPU (Colab Pro, 40 GB VRAM)
- High-core Intel Xeon / AMD EPYC cloud CPUs and multi-gigabit cloud networks.
- Zero thermal or memory stress on your local machine.
- Generates a pre-computed tactical mission bundle (`prism_colab_bundle.zip`)
  that imports into the PRISM Command Center in under 2 seconds!

The ready-to-run notebook is located at:
`colab/prism_reconstruction.ipynb`

4. STEP 3: CELL COMMANDS & EXECUTION ORDER
================================================================================
Run each cell sequentially from top to bottom (press Shift + Enter on each cell):

------------------------------------------------------------------------------
CELL 1: ENVIRONMENT SETUP & HARDWARE VERIFICATION
------------------------------------------------------------------------------
- Runs `!nvidia-smi` to verify GPU specs and CUDA version.
- Installs COLMAP, FFmpeg, and OpenGL libraries via apt-get.
- Installs Open3D, Ultralytics YOLOv8, OpenCV, and SciPy via pip.
- Execution time: ~45 seconds.

------------------------------------------------------------------------------
CELL 2: FLIGHT MEDIA & TELEMETRY ACQUISITION
------------------------------------------------------------------------------
- Mounts Google Drive (or accepts file upload).
- Validates the existence and size of your video and SRT subtitle.
- Sets up workspace directories: `/content/prism_workspace/`.
- Execution time: ~5 seconds.

------------------------------------------------------------------------------
CELL 3: SMART 4K VIDEO KEYFRAME DECIMATION
------------------------------------------------------------------------------
- A 10-minute 4K video contains 18,000 frames. Processing all 18,000 frames 
  is redundant and wastes memory.
- Select your desired Quality Preset from the dropdown:
    * `fast`     : ~45 frames (quick tactical draft, ~3-4 min)
    * `standard` : ~80 frames (NTRO Competition Standard, ~8-12 min)
    * `high`     : ~120 frames (Dense multi-view cloud, ~15-20 min)
    * `ultra`    : ~180 frames (Ultra detail + Blender Mesh, ~20-25 min)
- Runs Laplacian variance blur detection to skip motion-blurred frames.
- Downscales 4K to 1080p height for 4x faster SIFT feature extraction while 
  retaining full sub-pixel photogrammetric precision.
- Generates `frame_index.json` with frame numbers and timestamps.
- Execution time: ~1-2 minutes.

------------------------------------------------------------------------------
CELL 4: FLIGHT TELEMETRY & GNSS TIME SYNCHRONIZATION
------------------------------------------------------------------------------
- Parses DJI SRT brackets (`[latitude: ... longitude: ... rel_alt: ...]`).
- Matches each extracted keyframe timestamp to real-world WGS-84 coordinates.
- Generates `flight_telemetry.json` with exact GPS center and flight datum.
- If no SRT was provided, generates an autonomous visual flight datum (25m AGL).
- Execution time: ~2 seconds.

------------------------------------------------------------------------------
CELL 5: GPU-ACCELERATED COLMAP 3D PHOTOGRAMMETRY
------------------------------------------------------------------------------
- Runs GPU SIFT feature extraction (`--SiftExtraction.use_gpu 1`).
- Runs sequential image matching (`--SiftMatching.use_gpu 1`).
- Solves camera trajectory and sparse 3D point cloud via COLMAP Mapper.
- For high/ultra presets: runs CUDA Patch-Match Dense Stereo and depth fusion.
- Exports initial high-precision point cloud to PLY.
- Execution time: ~3 to 15 minutes (depending on preset).

------------------------------------------------------------------------------
CELL 6: METRIC GEOREFERENCING & GROUND LEVELING
------------------------------------------------------------------------------
- Reads the COLMAP point cloud and fitted camera poses.
- Performs RANSAC ground plane segmentation and aligns the terrain to the Y-up 
  frame (x = East, y = Up, z = -North).
- Sets ground level at y = 0.
- Calibrates true physical scale (1 unit = 1 meter).
- Saves the permanent high-density metric point cloud:
  `actionable_threat_map_points.ply` (and `actionable_threat_map.ply`).
- Execution time: ~10 seconds.

------------------------------------------------------------------------------
CELL 7: WATERTIGHT BLENDER 3D MESH SYNTHESIS (POISSON RECONSTRUCTION)
------------------------------------------------------------------------------
- Runs Screened Poisson Surface Reconstruction using Open3D.
- Filters boundary noise and fringe triangles.
- Transfers true drone photogrammetry RGB colors from the point cloud onto 
  the mesh vertices.
- Exports:
    * `actionable_threat_mesh.ply` (polygonal 3D surface mesh with vertex colors)
    * `actionable_threat_mesh.obj` (Wavefront OBJ for Blender 3D modeling)
- Encodes an optimized H.264 video stream: `drone_flight.mp4` (1080p, 30fps)
  ready for the PRISM live video viewport.
- Execution time: ~30 to 60 seconds.

------------------------------------------------------------------------------
CELL 8: PACKAGE & DOWNLOAD PRISM CLOUD BUNDLE
------------------------------------------------------------------------------
- Compresses all generated assets into: `prism_colab_bundle.zip`.
- Automatically triggers a browser download to your local machine.
- Also copies the zip to `/content/drive/MyDrive/prism_colab_bundle.zip`
  so your output is never lost even if the browser closes!
- Bundle contents:
    * `actionable_threat_map_points.ply` : 100,000+ true photogrammetry dots
    * `actionable_threat_map.ply`        : Active georeferenced display cloud
    * `actionable_threat_mesh.ply`       : Watertight Blender 3D surface mesh
    * `actionable_threat_mesh.obj`       : Wavefront Blender 3D model
    * `flight_telemetry.json`            : GPS coordinates & metric scale
    * `frame_index.json`                 : Keyframe timestamp registry
    * `drone_flight.mp4`                 : Web-streamable UAV camera video
    * `drone_flight.srt`                 : Subtitle telemetry track
- Execution time: ~15 seconds.

   Total deployment time: ~2 seconds! Zero strain on your local GPU!

6. STEP 5: SEAMLESS DOTS VIEW VS MESHIFY VIEW IN THE PRISM DASHBOARD
================================================================================
A core enhancement in PRISM ensures that toggling between Dots (Point Cloud) 
and Blender 3D Mesh preserves 100% position lock:

- To inspect the true photogrammetric dots:
  Click "Points (Point Cloud)" or Format ▾ -> "Points (Point Cloud)"
  The viewer displays the original high-density point cloud dots with their
  authentic drone photogrammetry colors.

- To inspect the smooth polygonal surface:
  Click "Solid 3D Mesh" or Format ▾ -> "Solid 3D Mesh"
  The viewer displays the watertight Poisson Blender 3D model.

- Switching back to Dots:
  When you click back to "Points", the dots are in the EXACT SAME spatial 
  coordinates as before. No shifts, no rotations, no floating artifacts.
  The original point cloud is permanently safeguarded in 
  `data/models/actionable_threat_map_points.ply`.

7. TROUBLESHOOTING & FAQ
================================================================================
Q: Colab disconnects during long video processing?
A: In Colab Pro, enable "High-RAM" and disable browser sleeping. For 3.5GB 4K 
   videos, using Method A (Google Drive Mount) and selecting `standard` (80 frames)
   or `high` (120 frames) completes the entire pipeline in under 12 minutes,
   well within free Colab limits.

Q: Video has no GPS SRT subtitles?
A: Colab Cell 4 automatically detects the absence of an SRT file and synthesizes 
   an autonomous visual flight datum with RANSAC ground leveling. The model is 
   still exported in upright metric meters (scale factor 1.0).

Q: Can I open the 3D model in Blender?
A: Yes! The bundle contains `actionable_threat_mesh.obj`. In Blender, click
   File -> Import -> Wavefront (.obj) and select `actionable_threat_mesh.obj`.
